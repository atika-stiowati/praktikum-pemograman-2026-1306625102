## 1. Problem Statement
> Membuat program untuk membaca data mahasiswa dari file EXcel DataNilai.xlsx, menghitung nilai akhir berdasarkan bobot yang ditentukan, menentukan grade, serta menampilkan laporan dan rekapitulasi jumlah mahasiswa berdasarkaan grade?
## 2. Mathematical Equation
> \[NA = (0.30 \times NL2) + (0.35 \times UTS) + (0.35 \times UAS)\] atau N A= (0,30 x NL2) + (0,35 X UTS) + (0,35 X UAS)

## 3. Algorithm
> 1. mulai
> 2. baca data mahasiswa dari file Excel DataNilai.xlsx.
> 3. inisialisasi variabel untuk menghitung jumlah mahasiswa berdasarkan grade.
> 4. ambil nama mahasiswa dan nilai NL2,UTS,serta UAS
> 5. hitung nilai akhir menggunakan rumus N A= (0,30 x NL2) + (0,35 X UTS) + (0,35 X UAS)
> 6. tentukan grade berdasarkan rentang nilai akhir yang telah di tetapkan
> 7. tampilkan nomor, nama mahasiswa, nilai akhir, dan grade
> 8. ulangi proses untuk seluruh data mahasiswa menggunakan perulangan
> 9. tampilkan rekapitulasi umlah mahasiswa pada setiap grade dan total mahasiswa
> 10. selesai.
